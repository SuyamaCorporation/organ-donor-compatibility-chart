# Organ Donor Blood Type Compatibility Chart
Interactive ABO blood type compatibility matrix for transfusion components with click-to-explain cells and print support.
## Features
- Donor × recipient compatibility matrix for red blood cells, whole blood, plasma, and platelets
- Color-coded cells: green for compatible, red for incompatible
- Click any cell to see an explanation of why the types are or are not compatible
- Filter buttons to switch between component types
- Print-friendly CSS for physical reference copies
## Tech
Static SPA · Tailwind CDN · localStorage
